# Python 与 R 结果核验报告

## 一、结论

两套结果**不一致**，且差异不是由 Python `statsmodels` 与 R `lme4/lmerTest` 的正常数值实现差异造成的。

老师的 R 结果可由交付数据通过以下两项操作几乎精确复现：

1. 将因变量从论文主模型规定的 `Sinclair_Total` 改为原始举重总成绩 `Total`；
2. 删除 `JetLag_abs == 12` 的全部 103 条记录。

执行这两项操作后，样本恰好由 Python 的 2186 条、730 名运动员变为老师报告的 2083 条、726 名运动员；LRT 也精确复现为 χ²=28.4950、df=10、p=0.0015033。

因此，当前问题本质上是**因变量选错 + 12 小时分组边界处理不一致**，而不是 R 与 Python 的统计软件差异。

## 二、主结果逐项核对

| 项目 | Python 交付主模型 | 老师 R 结果 | 是否一致 |
|---|---:|---:|---|
| 观测数 | 2186 | 2083 | 否 |
| 运动员数 | 730 | 726 | 否 |
| 因变量 | `Sinclair_Total` | 实际拟合结果对应 `Total` | 否 |
| 时差整体 LRT | 53.2699，p=6.63×10⁻⁸ | 28.4950，p=0.001503 | 否 |
| TravelDuration | β=-0.2182，p=0.0010 | β=-0.001717，p=0.9803 | 否 |
| East 8–9h | β=-5.5841，FDR p=0.0010 | β=-4.6662，FDR p=0.0168 | 否 |
| West 10–11h | β=+5.1653，FDR p=0.0307 | β=+2.1863，FDR p=0.7455 | 否 |

两套结果只有研究方向上的宽泛结论相似（时差整体检验显著、East 8–9h 为负），具体效应量、显著组、旅行时长效应及样本均不一致，不能混用。

## 三、证据链 1：老师实际拟合的是 `Total`

老师工作簿中的固定效应为：

- Intercept = 342.4913
- SexFemale = -120.9819
- TravelDuration_c = -0.001717
- East 8–9h = -4.6662

在交付数据中删除 `JetLag_abs == 12` 后，以 `Total` 为因变量拟合相同随机截距模型，Python 复现为：

- Intercept = 342.5054
- SexWomen = -121.0060
- TravelDuration_c = -0.001702
- East 8–9h = -4.6707

差异仅为不同软件优化器及自由度近似造成的末位小数差异。相比之下，以 `Sinclair_Total` 为因变量时，相应结果约为：

- Intercept = 433.57
- SexWomen = -149.46
- TravelDuration_c = -0.2355
- East 8–9h = -5.4144

老师工作簿的估计值与 `Total` 模型逐项吻合，而与 `Sinclair_Total` 模型明显不符。老师工作簿的 EMMeans 约为 277–284，也与原始 `Total` 均值 283.70 同量级；交付数据的 `Sinclair_Total` 均值为 362.62。

最可能的直接原因是 R 公式中写成了类似：

```r
Total ~ Sex + JetLagGroup_dir + TravelDuration_c + (1 | Athlete_ID)
```

而正确主模型应为：

```r
Sinclair_Total ~ Sex + JetLagGroup_dir + TravelDuration_c + (1 | Athlete_ID)
```

## 四、证据链 2：R 端删除了恰好 12 小时的记录

交付数据中：

- 总样本：2186；
- `JetLag_abs == 12`：恰好 103 条；
- 删除这些记录后：2186 - 103 = 2083；
- 删除前运动员数：730；
- 删除后运动员数：726。

这与老师报告的 2083 条、726 名运动员完全一致。

103 条边界记录包括：

- `JetLag_signed == -12`：50 条，Python 归入 `West_10-11h`；
- `JetLag_signed == +12`：53 条，Python 归入 `East_10-11h`。

其中只有 4 名运动员的全部记录都位于该边界，因此删除后独立运动员数恰好减少 4。

最可能的 R 端原因是使用 `cut()` 或显式条件时，将最高档定义为左闭右开区间 `[10, 12)`，导致数值 12 被生成为 `NA`，随后在完整案例筛选或建模时被删除。例如：

```r
cut(x, breaks = c(..., 10, 12), right = FALSE)
```

该写法不会包含最右端点 12。应显式处理 12 小时边界，例如先将圆周差统一映射，明确决定 `+12/-12` 的方向，再保证末档包含端点。需要注意：圆周上的 +12 与 -12 代表同一个对跖点，方向本身存在数学上的约定性，不能仅靠普通 `cut()` 默认处理。

## 五、LRT 的精确复现

用 2083 条子样本、`Total` 因变量、ML 拟合比较：

- 完整模型 logLik = -9484.9723174；
- 去掉 JetLagGroup 的简化模型 logLik = -9499.2198407；
- LR = 2 × (-9484.9723174 + 9499.2198407) = 28.4950465；
- df = 10；
- p = 0.0015033359。

以上数字与老师工作簿逐位一致。这进一步排除了“R 和 Python 软件实现不同”作为主要原因。

## 六、为何结论发生实质改变

### 1. `Total` 与 `Sinclair_Total` 不是可互换的结局

`Total` 是实际举起总重量，强烈受体重级别和性别影响；`Sinclair_Total` 是按 Sinclair 系数标准化后的成绩。研究若要跨性别、跨体重比较表现，二者代表不同科学问题。

老师模型中 Sex 系数约为 -121，而 Python Sinclair 模型约为 -150，也说明当前 Sinclair 变换并没有简单消除性别差异；但这不改变“论文规定结局必须统一”的要求。应先确认论文最终研究问题，再固定唯一结局变量。

### 2. 删除 ±12 小时记录改变了两个最高时差组

被删除的 103 条全部来自 East/West 10–11h 档，直接改变这两个组的样本量、组均值及与旅行时长的共线结构。因此 West 10–11h 从 Python 模型的 β=+5.17、FDR p=0.031，变为老师模型中的 β=+2.19、FDR p=0.745，不能视为随机波动。

### 3. TravelDuration 的结论相反主要由结局变量改变导致

Python Sinclair 主模型中旅行时长为 β=-0.218/小时，p≈0.001；老师的原始 Total 模型为 β≈0，p≈0.98。故“旅行时间没有独立影响”只适用于老师实际运行的 `Total` 模型，不能写入以 `Sinclair_Total` 为结局的论文主结果。

## 七、次要的软件实现差异

在统一数据、因变量、公式和估计方法后，仍可能出现很小差异：

- Python `statsmodels` 和 R `lme4` 的优化器、收敛容差不同；
- R `lmerTest`/`emmeans` 常用 Satterthwaite 或 Kenward–Roger 自由度，Python 当前结果使用渐近 z 检验；
- 置信区间和 p 值的自由度方法不同；
- LRT 必须统一使用 ML，最终参数报告通常使用 REML；
- 因子参考水平和对比编码必须明确设定。

这些差异只能解释末位小数或接近阈值时的小幅 p 值变化，不能解释本次 N=103、结局量纲、LRT 和 TravelDuration 结论的巨大差异。

## 八、老师工作簿本身的文件结构问题

`JetLag_LMM_Results.xlsx` 的工作表 XML 实际包含结果，但每张表的 `dimension` 都错误写成 `A1`，且关系文件引用了不存在的 drawing XML。由此：

- `openpyxl` 只读模式会误判每张表为 1×1；
-普通模式会因缺失 drawing 文件而报错；
- Excel/WPS 可能仍能容错打开。

这不改变统计结果，但会妨碍自动核验和复现。建议老师从 R 重新导出一个结构正常的 xlsx，或同时保留 CSV。

## 九、建议的统一重跑规范

1. 明确主结局为 `Sinclair_Total`，不要在 R 中重新选择或重算成 `Total`。
2. R 直接读取 `final_model_data_N2186.csv`，先核验：
   - `nrow(data) == 2186`
   - `n_distinct(Athlete_ID) == 730`
   - `sum(JetLag_abs == 12) == 103`
3. 不要重新 `cut()` 已经提供的 `JetLagGroup_dir`；优先直接使用交付数据中的最终分组列。
4. 显式设置参考水平：

```r
data$Sex <- relevel(factor(data$Sex), ref = "Men")
data$JetLagGroup_dir <- relevel(factor(data$JetLagGroup_dir), ref = "Minimal(0-1h)")
```

5. 主模型统一为：

```r
Sinclair_Total ~ Sex + JetLagGroup_dir + TravelDuration_c + (1 | Athlete_ID)
```

6. LRT 比较时两模型都用 ML（`REML = FALSE`）；最终固定效应、方差和 ICC 再用 REML 报告。
7. 事后比较只比较 10 个非参照组与 Minimal，统一使用 BH-FDR。
8. 重跑前还应解决项目已有质控问题：两条完全重复记录、同名不同运动员 ID、实际比赛日期/夏令时、年份或届次控制、共享暴露聚类以及 leave-one-nation-out 稳健性。

## 十、最终判断

当前老师 R 结果不能用于核验或替代 Python 的论文主模型结果。应先修正 R 端因变量和 12 小时边界，保证样本与公式完全一致后再比较。修正后，固定效应估计通常应只剩软件实现层面的微小差异；若仍有明显差异，再检查因子参考水平、ML/REML、自由度方法和缺失值处理。
