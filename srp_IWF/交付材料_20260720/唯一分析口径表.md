# 唯一分析口径表（Single Source of Truth）

生成依据：对当前仓库最终可执行代码链路（`preprocess2-athlete.py → merge_travel.py →
LMM_jetlag_v2.py / LMM_jetlag_travel_v2.py → heterogeneity_analysis.py`）逐项核实，
所有结论均可在对应脚本中定位复核。写 Methods/Results 前，任何数字/定义与本表冲突，
以本表为准；本表与代码冲突，以代码为准（并需回来更新本表）。

---

## 1. 样本

- 最终建模样本：**N = 2186** 条观测，**730** 名运动员，**13** 个国家/地区。
- 国家筛选标准：**"总参赛记录数前20国家" ∩ "单项前10名出现次数前20国家"的交集**，
  实际计算结果为 ARM/CHN/COL/IRI/JPN/KAZ/KOR/MEX/RUS/THA/TPE/UKR/USA（13国）。
  产出脚本：`1_爬数据+筛选top13国家/count.py` → `top20_nation.xlsx`（"对比结果" sheet）。
  **不是"平均前十名名次"。**
- ⚠️ **已知数据 bug（待清洗）**：`YAMADA Masaharu_JPN`（56kg男子组选手）
  2010年有一条记录被误标为 `+75 kg Women`，导致该运动员同时被计入 Men 与 Women，
  造成 Men(392)+Women(339)=731 ≠ 总运动员数730。需人工核查原始 Excel 后修正该行
  Event/Sex 标签，再重跑一次主模型（预期对整体结果影响极小，但 Table 1 数字需更新）。
- 按记录数统计（未清洗前）：Men = 1118, Women = 1068。

## 2. Sinclair 系数（最终版，唯一采用）

```
Men:   A = 0.722762521, b = 193.609
Women: A = 0.787004341, b = 153.757
```
IWF 2021–2024 周期系数。**注意**：仓库内 `5_LMM-原始时差/` 与 `2_EDA初步分析/EDA1.py`
使用的是旧周期系数（Men a=0.751945,b=175.508; Women a=0.783497,b=153.655），
已被弃用，不代表最终分析，写 Methods 严禁引用。

## 3. 时差方向定义（最终版，唯一采用）

```
JetLag_signed = Venue_UTC_offset − Athlete_UTC_offset
（24小时圆周最短路径折叠到 [-12, 12]）
正值 = 比赛地在运动员东边 → 运动员向东飞（Eastward）
负值 = 比赛地在运动员西边 → 运动员向西飞（Westward）
```
定义脚本：`preprocess2-athlete.py::circular_jetlag_signed`，
下游 `LMM_jetlag_v2.py` / `LMM_jetlag_travel_v2.py` / `heterogeneity_analysis.py` 完全一致。

**早期 `preprocess.py`（已弃用）方向相反**：`athlete_off − venue_off`。
若初稿 Methods 写的是"运动员时区−赛地时区"，属旧定义，必须改为上述最终定义。

## 4. JetLagGroup_dir 分组规则

- 基于 `JetLag_signed`，2小时一档，共11档；
- 参照组 **Minimal**：操作定义为 `|JetLag_signed| < 2h`（标签写作 "0-1h"，为2h宽档整数标签惯例，
  不是严格0–1h）；
- 东/西各5档：2-3h / 4-5h / 6-7h / 8-9h / 10-11h（左闭右开，边界按代码归入上档）；
- **无样本因超出分组范围被删除**（圆周时差已限制在[-12,12]，必落入某一档）；
  仅因时区信息缺失（`JetLag_signed`为NA）而删除记录。

## 5. 旅行时长（TravelDuration）来源

- **起点不是"国家首都"**，是各国**官方举重训练基地城市**（人工整理，`check_data/collect_city.py`）：
  例：USA=Colorado Springs, RUS=Sochi, MEX=San Luis Potosi, TPE=Kaohsiung, THA=Chiang Mai。
- 团队人工查询"训练基地城市 → 历届比赛城市"的飞行时长，产出 `travel_time_merged.csv`
  （字段：Departure_Nation, Arrival_City, Duration_Hours(h), Year）。
- 合并方式：按 **Nation + City（标准化）+ Event_Year** 左连接到主表（`merge_travel.py`）。
- 未匹配到旅行时长的记录，主模型阶段直接整体剔除（不是插补）。

## 6. 两个正式模型（都正确，用途不同）

| 模型 | 公式 | 核心数字（本次重跑） | 用途 |
|---|---|---|---|
| **主模型**（`LMM_jetlag_v2.py`） | `Sinclair_Total ~ Sex + JetLagGroup_dir + (1\|Athlete_ID)` | 整体LRT: LR=51.82,p=1.23e-7；East 8-9h: β=−7.77, d=−0.59 | 论文正文（**目前口径**） |
| **稳健性模型**（`LMM_jetlag_travel_v2.py --mode control`） | `Sinclair_Total ~ Sex + JetLagGroup_dir + TravelDuration_c + (1\|Athlete_ID)` | LRT-A: p=9.8e-4；LRT-B: LR=53.27,p=6.6e-8；East 8-9h: β=−5.58, d=−0.42 | 排除旅行疲劳解释的稳健性检验 |

## 7. Cohen's d 公式（已修正）

```
d = β / σ_ε        （σ_ε = REML残差标准差 = sqrt(scale)，不是残差方差）
```
主模型 σ_ε ≈ 13.21；稳健性模型 σ_ε ≈ 13.21（两模型残差方差接近）。

## 8. 写作措辞限制（非代码问题，写作规范）

- 交互项LRT不显著 → 只能写"未发现效应修饰的证据"（absence of evidence ≠ evidence of absence），
  不能写"证明各亚组同质"或"普遍统一的生理现象"。
- 控制旅行时长后效应仍显著 → 只能写"该效应不能被旅行疲劳解释"，
  不能写"证明纯粹独立的生理机制"（观察性设计无法排除其他混杂变量）。
